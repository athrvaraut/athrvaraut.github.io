# athrvaraut.github.io

Personal portfolio of Athrva Raut.

- `page.html` is the page itself. Edit this file.
- `build.py` wraps it into `index.html`, the file GitHub Pages serves. Run `python build.py` after every edit.
- `Athrva_Raut_Resume.pdf` is the resume the page links to. Replace it when the resume changes.

## Publish on GitHub Pages

1. Create a public repository named exactly `athrvaraut.github.io`.
2. Push this folder to it.
3. The site goes live at https://athrvaraut.github.io within a minute or two.
